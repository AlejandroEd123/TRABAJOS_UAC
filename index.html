Proceso
Registro de matrícula de estudiantes
Objetivo
Inscribir al estudiante en sus cursos, sin cruces de horario y a tiempo.
Cliente / usuario
El estudiante — la universidad usa los datos para planificar aulas.
El ciclo de vida BPM, paso a paso
01
Identificar / Diseñar
¿Qué proceso gestionamos?
Se abre el periodo de matrícula; se detecta el problema: colas y saturación.
›
02
Modelar
¿Cómo funciona?
Login → validar deuda → elegir cursos → verificar cupo y prerrequisitos → confirmar.
›
03
Ejecutar
¿Qué se necesita?
El estudiante se matricula en el aula virtual; el sistema registra en tiempo real.
›
04
Monitorear
¿Funciona bien?
Se miden tiempo de matrícula y matrículas sin error (ver indicadores).
›
05
Optimizar
¿Qué mejorar?
Se corrige la saturación con turnos escalonados (ver mejora).
↺ La mejora reinicia el análisis del proceso

Roles BPM

PatrocinadorVicerrectorado Académico — aprueba y financia
DueñoJefe de Registros Académicos — responde por el proceso
AnalistaOficina de sistemas — diseña y mejora el flujo
ParticipantesEstudiantes y registros — ejecutan la matrícula
Especialista TISoporte — mantiene sistema y base de datos

Indicadores

Tiempo promedio de matrícula
Minutos desde el login hasta el comprobante.
% de matrículas sin error
Sin cruces de horario ni rechazos por prerrequisito.

Optimización

ProblemaEl sistema se satura y se cae el primer día.
↓
CausaTodos se matriculan a la misma hora.
↓
MejoraTurnos escalonados por código o ciclo.
